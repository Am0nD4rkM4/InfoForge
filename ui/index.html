1 · Generador de comandos

Escribe el objetivo, marca las opciones y copia el comando. La UI no ejecuta nada por sí sola: el framework se ejecuta en tu terminal de Kali.

python3 infoforge.py target www.intercambiosvirtuales.org --stealth --ports common --output json

Modo sigiloso: delays 1.5–4.5 s, 5 hilos, UA rotativo, puertos aleatorios, sin banner grabbing. No te hace invisible.
